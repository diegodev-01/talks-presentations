03 // Hardware

Un cerebro de $5 para un cuerpo de los 90

El ESP32 es el traductor: mueve la cámara en dos ejes y habla con la nube por Wi-Fi.

  • ↔️Pan: un servo barre la cámara de izquierda a derecha.
  • ↕️Tilt: un segundo servo la inclina arriba y abajo.
  • 📡Wi-Fi integrado: sin gateway ni hardware extra, directo a AWS.

06 // Bitácora

Qué se rompió, qué aprendimos

🔗 Lo viejo conoce lo nuevo hardware
Una cámara de los 90 no tiene API ni Wi-Fi. El ESP32 fue el traductor entre el hardware viejo y la nube.
⏱️ Cada salto suma latencia nube
Cámara → stream → función → IA → alerta. Enviar cuadros pequeños y filtrar temprano para que la alerta se sienta en tiempo real.
🧩 Tres mundos, un sistema integración
Hardware, YOLO y AWS hablan idiomas distintos. Acordar un formato de mensaje simple entre cada etapa.
🔔 Demasiadas falsas alarmas ajuste
Un gato no es un intruso. Los umbrales de confianza deciden qué vale la pena para despertar a alguien.
